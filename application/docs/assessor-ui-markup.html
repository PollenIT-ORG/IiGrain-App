🌱 iiGrain - Assessor App Markup

Cross Platform (iOS & Android) · Role-gated view · Complete Flow + UI (no API) · sibling of the Farmer markup
📋 Scope of the assessor. The assessor fills assessments only for the farmer(s) assigned to them (not all farmers). For an assigned field they conduct their own independent assessment - a brand-new, separate assessment of that field, using the exact same form as the farmer (every question, score 0-3 + comment + evidence). It is not a review of the farmer's answers: the assessor fills every question themselves, regardless of what the farmer did. A field can hold two records - one “By Farmer”, one “By Assessor” - each independent. 🔒 On submit it locks (complete) - there is no admin review / sign-off; submitting finalizes it and it can't be edited. Every submission is stamped with the submitter's user id + role (“Submitted by Farmer / Assessor”) and shows in History.

6. Assessor Rules
  • Assesses only assigned farmers.
  • Conducts an independent, fresh assessment of the field - the same form as the farmer, every question.
  • Separate from the farmer's: a field can hold a “By Farmer” and a “By Assessor” record.
  • On submit it completes & locks - no admin review; can't be edited after.
  • Stores submitter id + role; shows in History.
7. Notes (flow + UI only)
Scope: markup only - no API
Form: reuse farmer assessment 1:1
Assessment: assessor's own, fresh & independent
Submit: completes - no admin review
Locked: after submit, can't edit
Fields: inline “See more”, no new screen
History: farmer + assessor records
