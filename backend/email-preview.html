Email templates

All transactional emails, rendered at size beside the event that sends them. Sample data shown.

11 templates
01 verifyEmailEmail

Trigger

Sign-up / resend verification

When it fires

POST /auth/register | on a fresh signup, and again if an unverified email registers a second time.

ToNew user (the person signing up)
SubjectVerify your email | iiGrain
02 signInCodeEmail

Trigger

Passwordless sign-in

When it fires

POST /auth/request-otp | user asks for a one-time login code.

ToExisting user logging in without a password
Subject735210 is your sign-in code
03 resetPasswordEmail

Trigger

Forgot password

When it fires

POST /auth/forgot-password | user requests a reset code.

ToUser who forgot their password
SubjectReset your iiGrain password
04 welcomeUserEmail

Trigger

Admin creates an account

When it fires

Admin creates a user (assessor / farmer / etc.). Carries the temporary password + a nudge to change it.

ToA user an admin just created
SubjectYour iiGrain account is ready
05 passwordChangedEmail

Trigger

Password changed (security)

When it fires

POST /auth/reset-password AND POST /profile/change-password | a confirmation so account takeover is noticed.

ToThe account owner
SubjectYour iiGrain password was changed
06 newProgramEmail

Trigger

New program opens

When it fires

Admin creates an active program (POST /programs). Fans out to all org farmers so they can enroll.

ToEvery farmer in the organization
SubjectNew program available: Govt Rice Scheme 2027
07 enrolledInProgramEmail

Trigger

Enrollment confirmed

When it fires

Farmer self-enrolls (/enroll-self) or an admin enrolls them (POST /programs/:id/enrollments).

ToThe enrolled farmer
SubjectYou're enrolled in Govt Rice Scheme
08 assessorAssignedEmail

Trigger

Assessor assigned

When it fires

POST /assessor-assignments, enroll-with-assessor, or set-enrollment-assessor.

ToThe farmer
SubjectJohn Assessor is your assessor
09 visitStartedEmail

Trigger

Assessor starts a visit

When it fires

POST /visits | assessor begins travelling to a specific field. Farmer can then track live.

ToThe field's farmer
SubjectJohn Assessor is on the way to North Field
10 assessmentSubmittedEmail

Trigger

Assessment submitted

When it fires

POST /assessments/my/fields/:id/submit | a receipt with the score.

ToThe farmer who submitted (receipt)
SubjectAssessment submitted for North Field
11 assessmentSubmittedNoticeEmail

ToThe assigned assessor
SubjectRavi Kumar submitted an assessment for North Field
