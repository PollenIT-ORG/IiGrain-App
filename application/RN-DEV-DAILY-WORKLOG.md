# Mobile App – Work Report

**Project:** Regenerative Agriculture Project
**Prepared by:** Mobile App Developer (Android & iPhone)
**Updated on:** 5 August 2026

This report shows the mobile app work in simple words, from the first day until now, so anyone can understand it. Sunday is a weekly holiday, so it is not counted.

---

## Main Work (in short)

- Set up the app and made login, profile, and account screens.
- Made the farm, field, and survey (assessment) screens.
- Added evidence upload (photo, video, PDF) and the assessment flow.
- Added the map, live tracking, and the field outline (border) drawing tool.
- Prepared the app for Android and iPhone, and kept fixing bugs and testing.
